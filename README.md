# GridPilot AI prototype

Interactive, static review prototype for the GridPilot client and administrator experience.

**[Open the live prototype](https://qisunnnn.github.io/gridpilot-review-prototype/)**

The `Survey_Explorer_Edit.html` page contains the intake specification. All assets are included in this repository; no build step is required. You can also open `index.html` locally.

This prototype does not call live AI services or send email. Demo progress and selected files are stored only in the visitor's browser.
